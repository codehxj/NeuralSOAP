# NeuralSOAP

**Structure-Aware 3D Molecular Generation with SOAP-Guided Neural Fields**

Official implementation of **NeuralSOAP**, an all-atom 3D molecular generative framework that combines continuous neural fields, SOAP-derived structural representations, Neural Empirical Bayes (NEB), and walk–jump sampling (WJS).

The paper **“NeuralSOAP: Structure-Aware 3D Molecular Generation with SOAP-Guided Neural Fields”** has been accepted for an **oral presentation at APBC 2026 (24th Asia Pacific Bioinformatics Conference)**.

---

## Overview

NeuralSOAP represents a molecule as a continuous multi-channel atomic occupancy field. Each molecule is associated with:

- a learnable neural-field latent code \(z\), which captures global molecular variation;
- a molecule-level SOAP embedding \(s\), which summarizes local atomic environments.

The two components are combined into the joint latent representation

\[
c=[z;s].
\]

The empirical distribution of the joint codes is modeled with Neural Empirical Bayes. New molecular samples are generated by walk–jump sampling in latent space, followed by neural-field decoding and atom extraction.

The framework is evaluated on **QM9** and **GEOM-Drugs**, with additional controlled representation-transfer experiments on **MoleculeNet**.

---

## Main Contributions

- Continuous all-atom molecular representation using multi-channel occupancy fields.
- Shared MFN neural-field decoder with FiLM conditioning and per-molecule latent codes.
- SOAP-guided latent representation that combines global neural-field variation with local structural information.
- Neural Empirical Bayes modeling and walk–jump sampling in the joint latent space.
- Direct SOAP ablations using **z-only** and **shuffled-SOAP** controls.
- Evaluation on both **QM9** and **GEOM-Drugs**.
- Controlled MoleculeNet comparison using D-MPNN, SchNet, SOAP-only+MLP, and NeuralSOAP.

---

## Method

The overall generation pipeline is:

1. Convert each input molecule into a continuous multi-channel atomic occupancy field.
2. Compute the molecule-level SOAP descriptor.
3. Learn the neural-field latent code \(z\).
4. Project SOAP features into a compact embedding \(s\).
5. Form the joint representation \(c=[z;s]\).
6. Train a Neural Empirical Bayes denoiser on the empirical distribution of joint codes.
7. Sample new latent codes using walk–jump dynamics.
8. Decode the sampled code with the neural field.
9. Extract atom coordinates and atom types from the generated occupancy field.

The current model performs **unconditional 3D molecular generation**. Property-directed generation can be implemented by extending the latent model to a conditional distribution \(p(c\mid y)\).

A dedicated Python environment is recommended:

```bash
conda create -n neuralsoap python=3.10
```

## Datasets

### QM9

QM9 contains approximately 133,000 small organic molecules with DFT-optimized 3D geometries. The reported NeuralSOAP experiments use the atom types:

```text
C, H, O, N, F
```

The main QM9 generation benchmark uses **10,000 generated molecules**.

### GEOM-Drugs

GEOM-Drugs contains substantially larger and more flexible drug-like molecules and is used to evaluate whether the representation extends beyond the small-molecule QM9 setting.

### MoleculeNet

The controlled downstream evaluation includes:

- BBBP
- BACE
- Tox21
- SIDER
- ClinTox

The same fixed molecule assignments are used across the compared models. SchNet, SOAP-only+MLP, and NeuralSOAP use the same RDKit conformer for each molecule, while D-MPNN uses the corresponding 2D molecular graph.

## Training and Generation

### 1. SOAP Feature Precomputation

```bash
python precompute_soap.py
```

SOAP descriptors represent local atomic neighborhoods using smooth atomic densities and rotation-invariant power-spectrum features. Atom-level descriptors are aggregated into a molecule-level representation and projected to the embedding \(s\).

### 2. Train the Neural Field

```bash
python train_nf.py
```

The neural field learns continuous molecular occupancy fields conditioned on the latent code and SOAP embedding.

### 3. Infer Molecular Latent Codes

```bash
python infer_codes.py
```

The resulting latent codes are combined with SOAP embeddings to construct the empirical joint-code distribution.

### 4. Train the Latent Generative Model

```bash
python train_fm.py
```

The latent model is trained with the Neural Empirical Bayes denoising objective.

### 5. Generate Molecules

```bash
python sample_fm.py
```

Generation uses walk–jump sampling followed by neural-field decoding and atom extraction.

### 6. Evaluate Reconstruction

```bash
python eval_nf.py
```

## Main Experimental Configuration

The reported QM9 configuration uses:

- MFN decoder: 6 layers
- MFN hidden width: 2048
- conditioning-code dimension: 1024
- NEB denoiser: 6 residual blocks
- NEB hidden width: 4096
- optimizer: AdamW
- Stage-2 learning rate: \(10^{-3}\)
- weight decay: \(10^{-2}\)
- batch size: 1024
- EMA decay: 0.9999
- QM9 seed: 1234
- SOAP cutoff radius: approximately 4.0 Å
- SOAP \(n_{\max}=8\)
- SOAP \(l_{\max}=6\)
- NEB noise level: \(\sigma=0.9\)
- WJS walk steps: \(K=2000\)
- atom-extraction grid resolution: 0.25 Å
- occupancy threshold: 0.4

Hydra configuration files under `configs/` control the corresponding training and sampling settings.

## Direct SOAP Ablation

The contribution of SOAP is evaluated with two direct controls:

- **z-only:** the SOAP component is removed.
- **shuffled SOAP:** the molecule–SOAP correspondence is randomly permuted while preserving the latent dimensionality and architecture.

All variants use the same sampling, atom-extraction, and evaluation configuration.

| Model | Stable molecule ↑ | Valid ↑ | Valency W1 ↓ | Bond-length W1 ↓ | Bond-angle W1 ↓ |
|---|---:|---:|---:|---:|---:|
| z-only | 98.7 | 99.8 | 0.014 | 0.007 | 1.30 |
| shuffled SOAP | 98.5 | 99.7 | 0.015 | 0.008 | 1.38 |
| NeuralSOAP | **99.1** | **100.0** | **0.010** | **0.005** | **1.115** |

Correctly paired SOAP information improves all five reported metrics. Relative to z-only, NeuralSOAP reduces valency W1 and bond-length W1 by approximately 28.6% and bond-angle W1 by approximately 14.2%. Relative to shuffled SOAP, the reductions are approximately 33.3%, 37.5%, and 19.2%, respectively.

These ablations show that the improvement is associated with structurally matched SOAP information rather than simply increasing the latent dimensionality.

## Controlled MoleculeNet Evaluation

The controlled downstream comparison uses the same predefined molecule assignments across models.

For 3D-dependent models, the same RDKit conformer is used for each molecule. D-MPNN uses its native 2D molecular graph input.

For NeuralSOAP downstream adaptation:

- LoRA rank: \(r=8\)
- LoRA scaling parameter: \(\alpha=16\)
- LoRA target: linear layers producing FiLM scale and shift parameters
- optimizer: AdamW
- learning rate: \(10^{-4}\)
- maximum epochs: 100
- early-stopping patience: 10 epochs

| Method | BBBP | BACE | Tox21 | SIDER | ClinTox |
|---|---:|---:|---:|---:|---:|
| D-MPNN | 0.88 | 0.82 | 0.78 | **0.65** | 0.86 |
| SchNet | 0.82 | 0.75 | 0.74 | 0.59 | 0.70 |
| SOAP-only + MLP | 0.84 | 0.79 | 0.75 | 0.56 | 0.78 |
| NeuralSOAP | **0.89** | **0.84** | **0.79** | 0.62 | **0.88** |

NeuralSOAP gives the highest ROC-AUC on four of the five evaluated tasks, while D-MPNN performs best on SIDER. The SOAP-only baseline remains below the full model on all five tasks.
